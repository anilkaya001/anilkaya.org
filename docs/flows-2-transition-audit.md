# GitHub to Cloudflare transition audit

The source transfer, deploy gate and Flows data writers have separate success criteria. A passing site build proves that the Worker bundles. A published Worker version proves neither that all source history can be recovered nor that the next market session will archive exactly once. Use the receipts below before retiring the associated GitHub service. Environment-specific commands and rollback procedures belong in [DEPLOY.md](../DEPLOY.md).

## Nightly parity and real-data boundary

The nightly resolves a session from SPY bars and the 16:00 Eastern cutoff. A run requesting a specific session must stop before publication when the feed resolves a different date. The existing session gate skips ranked writes on a completed archive, but still refreshes pulse, sector premium and news. Use a durable execution claim independently of the immutable archive rows. Test the claim and delivery retry jointly. An unreadable archive must fail safely. An existing different dated payload must retain its original bytes. Dated retention defaults to 126 days, while permanent idea keys have stronger protection. A delayed recalculation using today's undated screener or chains cannot establish historical point-in-time parity. Preserve timestamped source responses for any cross-runtime ranking comparison. [Nightly entry point](../scripts/flows-pipeline.mjs) · [Session gate](../scripts/flows-nightly/archive.mjs) · [Archive refusal contract](../shared/flows-archive.js) · [Retention](../scripts/flows-nightly/store.mjs)

The dedicated fixture container packages the production nightly modules, the canonical golden suite and its inputs on pinned linux/amd64 Node 22.23.5. Its verifier runs offline and compares 574 synthetic payloads. During migration the native live byte receipt changed the alert size from 97,919 JavaScript code units to 97,933 UTF-8 bytes. Only the heartbeat file digest and its nested `run` digest changed in the manifest. This differential measures one transport correction. The fixture has no live data binding or production publication path. Keep a separate live-data rehearsal comparing per-key freshness, complete symbol cohort, source timestamps, missing rows, archive digests, runtime, peak memory, vendor calls/retries and D1 read/write counts against the incumbent. Confirm replay with no duplicate ranked writes. [Fixture image](../scripts/flows-container/Dockerfile) · [Golden suite](../tests/flows-pipeline-golden.mjs) · [Live serializer](../shared/flows-live-pass.js)

The user-facing Flows 2 acceptance remains the quantitative engine, cross-asset screener and live options tape. After transport parity, use one owner-authorized symbol and source session through all three surfaces. Capture the originating quote/chain snapshot, selected ticker and filters, forecast as-of, age of the last qualifying trade, empty/stale states and route latency on cold and warm loads. Separate an archive's market session, its collection instant and its replay time. A fixture run is evidence for deterministic software behavior. Evaluating forecast quality needs later observations held out from the original forecast and reporting by horizon and coverage.
